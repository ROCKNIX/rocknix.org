## Installation

### Step 1: Update Anbernic Control App

Boot into Android, then download and install the updated `AnbernicControl.apk` from the ROCKNIX firmware backup Google drive: https://drive.google.com/file/d/1RyMr4nWS402-thIrkEWIvnBZYmu0qlk8/view?usp=drive_link

This update is required to later install the ROCKNIX Android Bootloader (ABL).

### Step 2: Image SD card

First download the `SM4450` version of ROCKNIX from the [Latest Nightly Build](https://github.com/ROCKNIX/distribution-nightly/releases/latest) and follow the instructions listed on the [Install](../../../play/install/) page.

[![Latest Version](https://img.shields.io/github/release/ROCKNIX/distribution.svg?labelColor=dddddd&color=FF5555&label=Latest&style=flat#only-dark)](https://github.com/ROCKNIX/distribution-nightly/releases/latest) -->

### Step 3: Install ROCKNIX ABL

- Once you have written the image to an SD card, insert the card and boot into Android.
- In Android, copy the folder `rocknix_abl` from the SD card to the root of the Internal Storage.
- Launch the 'Handheld Settings' app, navigate to 'Advanced' -> 'Root Scripts' and import the `backup_abl.sh` and `flash_abl.sh` scripts from the `rocknix_abl` folder on Internal Storage.
- Navigate to 'Script Management' and run the `backup_abl.sh` script to backup the currently installed ABL.
- Navigate to 'Script Managmeent' and run the `flash_abl.sh` script to flash the ROCKNIX ABL.

### Step 4: Configure ROCKNIX ABL

- Restart your device, holding Vol- as it boots to enter the ROCKNIX ABL. Within the ROCKNIX ABL, use Vol- / Vol+ to navigate between options and Power to select.
- Navigate to 'Set device model' and select 'Anbernic RG 55G1'.
- Navigate to 'Switch boot mode' and switch it to 'Linux'.
- Navigate to 'Start' to boot into ROCKNIX.
